# CHATBOT-CODE
java projects demostrating TCP Sockets and Multithreading.

## 1. Basic 1 to 1 Chat
'CLIENT 1.java' + 'SERVER 1.java' - Single client connects to single server

## 2. Sequential Multi-Client
'CLIENT 2.java' + 'SERVER 2.java' - Multiple CLients, one at a time

## 3. Multithreaded Server
'CLIENT 3.java' + 'SERVER 3.java' - Multiple clients simultaneously

## How to Run
1. Compile: 'javac SERVER_X.java'
2. Run Server: 'java SERVER_X'
3. Run Client: 'java CLIENT_X' in new terminal.
